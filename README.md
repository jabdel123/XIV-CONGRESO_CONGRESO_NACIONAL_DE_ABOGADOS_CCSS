# XIV Congreso Nacional de Abogados de la CCSS

## Bot informativo

Repositorio del **Bot Informativo del XIV Congreso Nacional de Abogados de la Caja Costarricense de Seguro Social (CCSS)**.

### XIV Congreso Nacional de Abogados de la CCSS

**Tema:**  
“Gestión jurídica moderna: retos, tecnología y transformación en la CCSS”.

**Fecha:**  
27 de noviembre de 2026.

**Lugar:**  
Colegio de Abogados y Abogadas de Costa Rica, Zapote, San José.

## Objetivo

El bot informativo fue desarrollado como una herramienta digital de apoyo al XIV Congreso Nacional de Abogados de la CCSS, con el propósito de facilitar a las personas participantes el acceso rápido y sencillo a información relacionada con la actividad.

La herramienta permite consultar, entre otros contenidos:

- Información general del Congreso.
- Programa de actividades.
- Expositores y panelistas.
- Preguntas frecuentes.
- Información relacionada con la participación.
- Certificado de participación.
- Información de contacto.
- Acceso a recursos y enlaces relacionados con el Congreso.

La herramienta ha sido desarrollada como una aplicación web utilizando:

- HTML5
- CSS3
- JavaScript
- GitHub Pages

El bot funciona como un sitio web estático y no requiere instalación por parte de las personas usuarias.
